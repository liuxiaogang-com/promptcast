# 启动、授权与更新体验修复

- 启动应用时展示主窗口；默认使用 ⌘⇧P / Ctrl+Shift+P 唤起，保留已有自定义快捷键和禁用设置。
- 新增 macOS 辅助功能授权引导，自动检测授权状态，修复窗口层级与权限诊断页面换行问题。
- 移除设置页重复标题栏，使用系统原生窗口控制。
- 修复自动检查更新的运行时错误，以及快捷键注册失败时覆盖原配置的问题。
- 改进更新安装流程：准备成功后退出应用，保留旧应用备份，安装失败时尝试恢复。
- 账户请求不再阻塞界面；切换账户前提示清空本地内容，失败时回滚本地数据并暂停同步。
- 安装包仅保留 Windows EXE 和 macOS 通用 DMG。
