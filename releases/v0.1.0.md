# 本地图文管理与图片剪贴板

- 新增图文编辑，支持文字、粗体、斜体、列表和 PNG/JPEG/WebP 图片。
- 图片保存在应用本地数据库，支持插入图片、粘贴图片及独立预览。
- 剪贴板支持图片，可将文本或图片长期保存、加入收藏；清空历史不会删除已保存内容引用的图片。
- 图文内容明确标记“仅本机”，暂不跨设备同步。已有文本转为图文时另存副本，原文本及其同步保持不变。
- 支持复制图片和图文；粘贴效果取决于目标应用支持的格式。
- 数据备份升级至版本 2，包含已保存图文和图片；支持导入旧备份，旧版应用不能导入新版备份。
- 增加图片大小、存储容量和内容格式检查；保存或导入失败时回滚，避免覆盖已有内容。

本版本不含附件管理或图片云同步。升级后请使用新版应用管理图文数据，不建议降级打开同一数据库。
