# 独立更新窗口与列表体验修复

- 更新提醒改为独立窗口，应用在后台运行、主窗口隐藏时也能显示提醒。
- 下载与安装分离：下载完成后等待用户点击“退出并安装”，不会自动打断使用；关闭更新窗口后可稍后继续安装。
- 安装前重新校验已下载文件，文件变化或丢失时要求重新下载。
- macOS 安装前后核对应用包版本，刷新应用路径注册并启动新实例，减少更新后误打开旧版本的情况。
- 剪贴板文字、图片、加载中与加载失败状态均按实际内容计算高度，修复时间和类型下方的多余留白。
- 全部、收藏和剪贴板的操作按钮默认隐藏且不占位，悬停或选中时显示。
- 修复 macOS 滚动条拖动与窗口背景拖动冲突，抽屉仅顶部标题区域允许移动窗口。

本次更新不修改已有内容、图片或数据库结构，也不增加使用统计。
旧版客户端升级到本版本时仍使用旧版的安装流程；新的下载确认流程从运行本版本后生效。
